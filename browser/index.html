Using the converter

From detector scans to GSAS

A practical guide to selecting inputs, choosing a reduction and interpreting the outputs. Help buttons in the workspace explain individual fields.

Start with a scan

  1. Wait for the Python runtime to be ready. Fetch & convert latest (one scan) downloads the NCNR Mn5Si₂ experiment and converts its latest complete scan by archive update time, using the current settings. Newer partial scans are left unselected. If multiple scans are already selected, the quick action stops without changing them and directs you to the selection-based conversion buttons.
  2. For more control, use Load NCNR scans or Add local files for .bt1 or prepared .raw inputs. NCNR downloads are checked against the archive’s SHA-256 hashes.
  3. Review the metadata, select scans, then use the separate-conversion button. Download the output files from Results.

Input filenames need unique basenames, using letters, digits, underscores, dots or hyphens.

Read the scan table

Measured temperature, in kelvin
The mean and recorded minimum–maximum come from acquisition measurements, not the sample description or temperature setpoint.
Monochromator and wavelength
The recorded monochromator, wavelength in ångströms (Å) and collimation in arcminutes (′).
Planned M4 range
Motor start, stop and step in degrees. This is not the full 2θ range covered by all detector banks or the exported GSAS pattern.
Acquisition versus archive time
The acquisition date and terminal end marker are shown as recorded; their timezone is not established. Start time is not recorded in these headers. Archive updated is a separate event shown in US Eastern time and is never used to estimate the acquisition start.

RAW files do not establish acquisition completeness, temperature or counting mode; unknown fields stay unknown.

Review suggested combinations

Suggestions use complete BT-1 scans with matching recorded instrument settings, scan geometry and detector scale/zero corrections. The largest minus smallest measured scan mean in the whole group must be at most 0.2 K; a chain of near-neighbours is not enough.

Matching metadata cannot establish sample identity or measurement state. Review the original descriptions, especially when they differ. Temperature drift within an individual scan is reported as a warning, even when the scan means match.

Select suggested group only changes checkboxes. It never converts or combines automatically.

Combine deliberately

Select two or more appropriate scans, set a combined output name under Combining scans, then choose Combine selected.

Each scan is prepared separately. Detector estimates are normalized and combined by inverse variance; raw counts are not simply added. The first selected file in table order supplies the normalization monitor and is named beside the conversion actions.

Instrument checks remain active; legacy mode also requires compatible detector grids and calibrations. The separate conversion guard refuses mean temperature differences above 1 K unless you explicitly acknowledge mixed temperatures. That guard is different from the 0.2 K suggestion rule.

Choose mode and uncertainty

Correct is the initial default: float64 arithmetic, enclosing measured intervals and independent variance propagation. GSAS retains fractional values where its fixed-width fields permit.

Legacy preserves historical float32 operation order, snapping, masks and endpoint rules, with integer GSAS output. Its default uncertainty interpolates sigma linearly.

Uncertainty is separately selectable: independent variance uses squared interpolation weights; legacy-linear interpolates standard deviations. Choosing independent uncertainty in legacy mode does not change its geometry or float32 precision.

Nearest assigns measured observations to nearest grid bins; overlapping estimates can still be combined.

Partial scans and missing bins

Incomplete acquisitions remain unselected by default. To convert a valid recorded prefix, choose correct mode and explicitly enable Allow incomplete acquisition prefixes. Legacy mode requires complete BT-1 scans.

Results retain a Partial snapshot label and completeness metadata. Missing acquisition rows are not invented. Missing output bins remain explicit zero-weight gaps, distinct from measured zero counts.

Partial-input and mixed-temperature acknowledgements reset when the page is reloaded.

Understand the downloads

GSAS / FullProf DAT / CSV / JSON
GSAS provides the uniform pattern. FullProf DAT uses XYDATA with explicit 2θ (degrees), intensity and sigma columns. Set INSTRM = 10. The exported header already contains INTER 1 1 0 0, which sets Interpol = 0 (no interpolation). Invalid bins are omitted; each new result reports how many. Explicit angles preserve the locations of gaps without filling them. CSV retains values before GSAS formatting; legacy values still originate in float32. JSON records source hashes, masks, policies and limitations.
RAW
A separate prepared detector-bank file is produced for each BT-1 input. These RAW files are not combined patterns; combined GSAS/DAT files are listed above them. Prepared RAW inputs do not need another RAW export.
Conditional covariance NPZ
Available only in correct mode with independent uncertainty. It stores a factor for correlations from shared observations, conditional on observed variances and fixed averaging weights. Ordinary GSAS fitting does not automatically use it.

Monitor and calibration uncertainty are not propagated. Matching detector corrections does not validate an instrument resolution profile. Some importers ignore nonpositive intensities despite positive uncertainty.

Keep your workspace and results

Input files and result blobs are cached locally in IndexedDB; localStorage holds preferences only. Reopening this site in the same browser can restore the workspace. Private browsing, storage limits or browser cleanup can remove cached data, so download copies for long-term storage.

Remove selected inputs keeps existing results. Clear saved workspace clears cached inputs and results, while leaving preferences, original source files and downloaded copies intact. If persistence fails, the workspace reports that new files remain in memory for this tab.
